- Do NOT diagnose mental health conditions.

- If analyzing multiple images, detect progression trends over time.

-----------------------------------------
SECTION 1 — VULNERABILITY DISPLAY PATTERN
-----------------------------------------

From single images and captions, evaluate whether the influencer displays public vulnerability signals:

Check for:

- Crying selfies or visible emotional distress
- Empowerment quotes after implied hardship
- “Healing era” or self-growth messaging
- Gym transformation framed as emotional rebirth
- Sad captions paired with polished visuals
- Contrast between public sadness vs aesthetic perfection
- Symbolic loneliness imagery (empty spaces, night shots, reflective poses)

Classify Vulnerability Display Type:
- None / Minimal
- Controlled vulnerability
- Strategic vulnerability (engagement-driven)
- Emotionally expressive
- Unstable emotional signaling (only if strong repeated evidence)

Score 1–10:
Public Vulnerability Intensity

Explain reasoning with references to observable patterns.

Authenticity Gap Score

Low score = cohesive persona
