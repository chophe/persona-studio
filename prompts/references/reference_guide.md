# Reference Guide for Image Analysis

This guide provides standards and conventions for analyzing images.

## Color Analysis

- Use standard color names (red, blue, green, etc.)
- Note color combinations and contrasts
- Describe color temperature (warm, cool, neutral)

## Composition Elements

- Rule of thirds
- Leading lines
- Framing
- Symmetry and balance

## Technical Aspects

- Resolution and clarity
- Lighting conditions
- Focus and depth of field
- Exposure and contrast
