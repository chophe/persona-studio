# Object Detection Prompt

Analyze this image and identify all objects present. For each object:

1. **Object Name**: What is the object?
2. **Location**: Where is it positioned in the image?
3. **Size**: Estimate its relative size (small, medium, large)
4. **Confidence**: How confident are you about this identification?

## Output Requirements

- List objects in order of prominence
- Use consistent naming conventions
- Include any uncertainties or ambiguities
